INTRODUCTION:

Bioinformatics plays an important role in the analysis of biological data, particularly in the study of evolutionary relationships between organisms. Thanks to computational tools and statistical methods, it is possible to compare DNA sequences, identify their similarities and differences, and then reconstruct phylogenetic trees that represent the kinship relationships between different species.
In this practical work, we will study the gene encoding the 16S ribosomal RNA (16S rRNA) in three bacterial species: Escherichia coli, Salmonella enterica and Klebsiella pneumoniae. The nucleotide sequences will be retrieved from the GenBank database, accessed through the National Center for Biotechnology Information (NCBI) platform.
After checking and preparing the sequences, we will perform global alignments using the Needleman–Wunsch algorithm. We will then calculate the genetic distances between the species from the aligned sequences and reconstruct two phylogenetic trees, one using the UPGMA method and the other using the Neighbor-Joining method. Finally, we will compare the trees obtained in order to interpret the evolutionary relationships suggested by the data.

Presentation of the 16S rRNA gene

The 16S rRNA gene encodes the 16S ribosomal RNA, an essential component of the small subunit of bacterial ribosomes. It is widely used in phylogenetics because it is present in all bacteria, has both conserved and variable regions, and is available in databases such as GenBank. The conserved regions make sequence alignment easier, while the variable regions make it possible to identify genetic differences between species. However, its strong conservation may limit the ability to distinguish between some very closely related bacteria.

We will work with the following three species:
- Escherichia coli (a bacterium frequently found in the human intestinal microbiota), the comparison species.
- Salmonella enterica (a bacterium that can cause infections in humans), to study genetic similarities with E. coli.
- Klebsiella pneumoniae (a bacterium that can cause infections, notably respiratory and bloodstream infections), to study the genetic distances to the other two species.

Objectives:

Reconstruct and compare the phylogenetic relationships between Escherichia coli, Salmonella enterica and Klebsiella pneumoniae from the sequences of their 16S rRNA gene

2_ Retrieval, identification and extraction of the sequences

The sequences were retrieved using the Entrez module of the Biopython library, which allows the NCBI databases to be queried and nucleotide records to be extracted. The sequences obtained were then examined in order to check the identity of the organisms, the annotation of the gene under study and the length of the regions retrieved.
The aim is to check the identity and quality of the 16S rRNA gene sequences in the three species, extract the corresponding regions and save them in a FASTA file named 16S_rRNA_only.fasta.

Script
from Bio import Entrez, SeqIO

Entrez.email = "regismnon@mail.com"

species = [ "Escherichia coli","Salmonella enterica","Klebsiella pneumoniae"]

# Output FASTA file
output_file = "16S_rRNA_only.fasta"

sequences = []

# --------------------------------------------------
# 2. Search and extraction of the 16S rRNA gene
# --------------------------------------------------
for sp in species:

    print(f"\nSearching for the 16S rRNA gene in: {sp}")

# Search in the NCBI Nucleotide database
    query = (f'"{sp}"[Organism] ' 'AND "16S ribosomal RNA"[Title]' )

    try:

        with Entrez.esearch(db="nucleotide",term=query, retmax=10) as handle:

            search_results = Entrez.read(handle)

        ids = search_results["IdList"]

        if not ids:
            print(f"No result found for {sp}.")
            continue

        print(f"{len(ids)} records found.")

# Retrieve the GenBank records
        with Entrez.efetch(db="nucleotide",id=ids,rettype="gb",retmode="text") as handle:

            records = list(SeqIO.parse(handle, "genbank"))

# --------------------------------------------------
# 3. Identification and extraction of the 16S rRNA gene
# --------------------------------------------------

        gene_found = False

for record in records:           # Check the organism

            organism = record.annotations.get("organism", "")

            if sp.lower() not in organism.lower():
                continue

            for feature in record.features:

                if feature.type == "rRNA":

                    product = feature.qualifiers.get( "product", [""])[0]            # Check that it is the 16S rRNA

                    if "16S ribosomal RNA" in product:

                        gene_sequence = feature.extract(record.seq)      # Build a FASTA record
                        fasta_record = SeqIO.SeqRecord(gene_sequence,id=sp.replace(" ", "_"),
                            description=(f"16S_rRNA accession={record.id}"))

                        sequences.append(fasta_record)

                        print("Sequence extracted successfully.")
                        print("Accession:", record.id)
                        print("Length:",len(gene_sequence), "nucleotides")

                        gene_found = True
                        break

            if gene_found:
                break

        if not gene_found:
            print(f"No usable 16S rRNA annotation "f"found for {sp}.")

    except Exception as e:
        print(f"Error for {sp} : {e}")

# --------------------------------------------------
# 4. Saving the sequences in FASTA format
# --------------------------------------------------

if sequences:
    SeqIO.write(sequences, output_file, "fasta")
    
    print("\nExtraction completed.")
    print("Number of sequences obtained:", len(sequences))
    print("File created:", output_file)

else:

    print("\nNo sequence could be extracted.")

3_ Performing global alignments with Needleman–Wunsch.

After extracting the sequences of the gene encoding the 16S ribosomal RNA in Escherichia coli, Salmonella enterica and Klebsiella pneumoniae, an alignment step was planned in order to compare their nucleotide sequences. It makes it possible to match the homologous positions of the sequences and to identify the nucleotide differences that may inform us about their evolutionary divergence.
This alignment will be carried out using the Needleman–Wunsch algorithm.
This algorithm performs a global alignment, i.e. it tries to align the sequences over their whole length. It is based on dynamic programming and assigns a score to matches, to differences (mismatches) and to insertions/deletions represented by gaps (-). The goal is to find the alignment with the best overall score. In our study, the Needleman-Wunsch algorithm will be applied to the 16S rRNA gene sequences obtained from the different species.
We will therefore start by performing the pairwise alignments:
- Escherichia coli and Salmonella enterica;
- Escherichia coli and Klebsiella pneumoniae;
- Salmonella enterica and Klebsiella pneumoniae.

The alignments will then be used to calculate the genetic distances, which will later be used to build the phylogenetic trees

Script
from Bio.Align import PairwiseAligner

# instantiate the class used to perform the alignment
aligner = PairwiseAligner()

# We specify that we use the Needleman-Wunsch algorithm
aligner.mode = "global"

# Scoring parameters
aligner.match_score = 1
aligner.mismatch_score = -1

aligner.open_gap_score = -2
aligner.extend_gap_score = -0.5

4_ Calculating a genetic distance matrix based on the p-distance.

Once the alignments have been examined, we can move on to calculating the genetic distances. We will use the p-distance, which corresponds to the proportion of comparable positions showing different nucleotides.
Its formula is:

p = NdNc

where:
Nd is the number of positions with different nucleotides;
Nc is the total number of comparable positions retained in the calculation.

A p-distance of 0 means that the two sequences are identical (excluding gaps), while a value close to 1 indicates that they are very different.

4-1_ Calculating the p-distance
Script
# select the best global alignment
def p_distance (seq1, seq2):
    alignment = aligner.align(seq1,seq2)[0]    #The best global alignment between seq1 and seq2 is computed with the aligner.
    aligned = alignment.format()                # extract the aligned sequences
    lignes = aligned.split('\n')

    seqA = ""              # store the sequences in seqA and seqB
    seqB = ""

    for line in lignes:
        if line.startswith("target"):
            seqA += line.split()[2]

        elif line.startswith("query"):
            seqB += line.split()[2]

    differences = 0
    compared = 0

    for a, b in zip(seqA, seqB):            #The two aligned sequences are scanned position by position.

        # ignore the gaps
        if a == "-" or b == "-":           #positions containing a gap (-) are not counted in the calculation
            continue

        compared += 1

        if a != b:
            differences += 1

    return differences / compared          #The p-distance is obtained by dividing the number of differences by 
                                              #the total number of compared positions (excluding gaps).

5_ Reconstruction of the phylogenetic trees with UPGMA and Neighbor-Joining.

A phylogenetic tree represents the kinship relationships between species based on their genetic characteristics. The tips, called leaves, correspond to the species studied, while the nodes represent their hypothetical common ancestors. Branch lengths can represent the evolutionary distances between the sequences, depending on the reconstruction method used.

To describe the structure of a tree, we use the Newick format, a standard text notation in bioinformatics. Parentheses indicate the groupings between species. For example, ((A,B),C); means that A and B share a more recent common ancestor with each other than with C. Branch lengths can be given after the : symbol. Thus, in ((A:0.10,B:0.10):0.05,C:0.15);, the numerical values represent the lengths of the corresponding branches.
The Newick format therefore makes it possible to represent simply the topology of a phylogenetic tree and, when available, the lengths of its branches.

Biopython uses the DistanceMatrix class; this class represents a distance matrix compatible with Biopython's phylogenetic tree construction algorithms, such as Neighbor Joining (NJ) and UPGMA.
